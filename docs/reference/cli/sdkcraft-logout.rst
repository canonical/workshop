sdkcraft logout
---------------

.. @artefact sdkcraft logout

Clear SDK Store credentials

.. rubric:: Usage

.. code-block:: console

   $ sdkcraft logout

.. rubric:: Description


Clear the locally stored SDK Store credentials.

If no credentials are found, a message is displayed and no action is taken.

See also :ref:`ref_sdkcraft_whoami` to verify that you are logged in,
and :ref:`ref_sdkcraft_login` for sign-in instructions.


.. rubric:: Examples


Log out:

.. code-block:: console

   $ sdkcraft logout

# Workshop 0.9.10 release notes

## 24 November 2026

These release notes cover new features and changes in Workshop 0.9.10.

## Requirements and compatibility

Workshop relies on Snap and LXD:

- See the [Tutorial](https://ubuntu.com/workshop/docs/tutorial/) for setup instructions.
- Refer to the [Contribution Guide](https://ubuntu.com/workshop/docs/contributing/) for development prerequisites.

Workshop now requires LXD 6.10 or later.

## What's new in 0.9.10

Workshop 0.9.10 makes virtual machine workshops generally available:
they no longer need an opt-in setting or a pre-release LXD channel, and they support SDKs.
Workshop definitions can now set the number of CPUs, the amount of memory,
and the root disk size of a workshop.
The CLI also gains short aliases for common commands.

### Workshop

**Repository:** <https://github.com/canonical/workshop>

- The virtual machine runtime is no longer experimental.
  The `workshop.experimental-vms` snap setting is gone,
  and SDKs work in virtual machine workshops on LXD from the stable channel.
- Workshop now requires LXD 6.10 or later, up from 6.8.
- New `cpus`, `memory`, and `disk` fields in the workshop definition
  set the number of CPUs, the amount of memory, and the root disk size of a workshop.
  Changes apply on the next `workshop refresh`,
  and `workshop info` reports the configured values.
- Virtual machine workshops now get 4 GiB of memory by default, up from LXD's 1 GiB,
  and a consistent 10 GiB root disk so that snapshots can be reused.
- Existing `workshop` ZFS pools are updated on refresh.
- New command aliases: `workshop ls` (`list`), `workshop rm` (`remove`),
  `workshop sh` (`shell`), `workshop ok` (`okay`), and `sdk ls` (`list`).
- The `custom-device` interface now connects USB devices.
- Fixed `workshop run` reporting the wrong exit status
  for actions that call `exit` explicitly.
- Fixed `workshop remount` failing for stopped virtual machine workshops,
  and mounts between workshops failing in virtual machines.
- The daemon no longer logs an nftables error
  on hosts without an `ip filter` table.

### SDKcraft 0.9.4 (unchanged)

**Repository:** <https://github.com/canonical/sdkcraft>

- No changes in this release.

### Docs

**Repository:** <https://github.com/canonical/workshop>

- Removed the opt-in steps from the virtual machine how-to.
- Documented the `runtime`, `cpus`, `memory`, and `disk` workshop definition fields.
- Added command aliases to the CLI reference.
- Refreshed Go SDK examples to Go 1.27.
